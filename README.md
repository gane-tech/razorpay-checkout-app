# Razorpay Checkout Integration App

A lightweight, front-end web application demonstrating a secure sandbox checkout flow using the official Razorpay JavaScript SDK.

## Features
- Dynamic product/service pricing display.
- Integrated Razorpay Test Mode checkout popup modal.
- Payment response callback handling to capture and display test transaction IDs.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Payment Gateway:** Razorpay Web SDK (Test Environment)

## How to Run Locally
1. Clone or download this repository to your local machine.
2. Open `index.html` directly in any modern web browser.
3. Click **"Pay Now with Razorpay"** and use Razorpay's test credentials to simulate a transaction.
